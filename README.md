### How often is OmniPatch updated to support new AI app versions?

We aim to release updates within a few weeks of major application updates to maintain compatibility and effectiveness.

### Does OmniPatch require an internet connection to work?

The patching process itself is offline. However, the AI applications it targets will need internet to function normally after activation.

### Will using OmniPatch affect my account with the AI service provider?

Yes, the original application files are backed up during the process, allowing you to restore them through the patcher's interface if needed.
